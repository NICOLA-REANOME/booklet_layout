Semantic search foundations

OpenRouter exposes an embeddings endpoint. Embeddings turn text into vectors, useful for finding relevant paragraphs in long books beyond exact keyword matching.

How it helps long books
  1. Split the manuscript into paragraphs or sections.
  2. Create and save an embedding for each section.
  3. Embed a user question and retrieve nearby sections.
  4. Send only relevant excerpts to the chat model.
This page tests the provider endpoint. A persistent vector index, chunk-management and retrieval store have not yet been added.
Connect your free API keys safely

Provider keys belong in Vercel Environment Variables, never in the GitHub repository or browser code. The app calls its own /api/ai server wrapper.

  1. Open the Vercel project settings.
  2. Add AGNES_API_KEY with your Agnes AI key.
  3. Add OPENROUTER_API_KEY with your OpenRouter key.
  4. Enable them for Production and Preview; save.
  5. Redeploy the project, then press Refresh status.

Request routing

Agnes AI uses its OpenAI-compatible text/vision chat endpoint, image generation endpoint and asynchronous video endpoint.

OpenRouter uses the chat-completions API with official HTTP-Referer and X-OpenRouter-Title: BookFlow Studio attribution, plus model discovery and embeddings.

The wrapper does not impersonate Claude Code or another client. OpenRouter sees BookFlow Studio as the requesting app.
